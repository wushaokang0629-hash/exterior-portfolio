# 室外建筑作品集

首页：Aurora + StaggeredMenu。分类：GooeyNav。项目墙：DriftWall。项目预览：DepthCarousel。全站鼠标：GlowCursor。

真实项目共 9 个、105 张图片。分类为建筑环境 3 项、公园绿地 4 项、交通景观 2 项；其余分类暂空。原始图片不修改，网页 WebP 副本位于 public/images/projects。项目名称、分类、封面和独立图片集集中在 app/portfolio-data.js。

组件官方源码位于 components/react-bits；DriftWall 增加项目名称显示。页面集成及配置在 app/Portfolio.jsx，样式在 app/globals.css。图片使用横向卡片并完整显示构图。

运行 npm install、npm run dev；构建 npm run build。
